# OjaLink Style Guide

Feeling: trusted, warm, busy-market-friendly. Phone size first.

## Colours
| Name | Hex | Use |
|---|---|---|
| Main (market green) | #0B6B3A | Main buttons, links, headers. White text on it is readable. |
| Accent (pepper orange) | #E8730C | Highlights, badges, "Featured". Use DARK text on it, not white. |
| Text | #1B1B1F | Body and headings |
| Muted | #5B5B66 | Small helper text |
| Background | #FAF7F2 | Page background (warm off-white) |
| Danger | #C62828 | Delete, cancel, errors |

Check any new colour pair at webaim.org/resources/contrastchecker (aim for 4.5:1 or more).

## Fonts (Google Fonts)
- Headings: Poppins, bold
- Body: Inter, regular

## Text sizes
- H1: 28px · H2: 22px · Body: 16px (never smaller) · Small: 14px

## Spacing and corners
- Spacing scale: 4, 8, 16, 24, 32, 48
- Corners: 8px on buttons and inputs, 12px on cards
- Shadows: soft and small, only on cards

## Buttons
- Main: green background, white text, 48px tall, full width on phones
- Second: white background, green border and text
- Danger: red background, white text, use only for delete or cancel

## Rules
- Tap targets at least 44px.
- Prices always in Naira, like ₦5,000.
- Compress images. No heavy fonts or scripts.
- Real content only. No lorem ipsum.
